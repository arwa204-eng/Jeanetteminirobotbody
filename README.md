These are some pictures of the Mini Robot. 🤖

It will be a **four-legged robot**, with **one degree of freedom for each leg**. I’ll be using **servo motors** to move the legs.

The main goal of this robot is to be a little companion during my boring days at university. 😭

I’m also planning to improve it by adding **AI**, so it can talk, or at least show the **date and random little things**.

This is just the beginning, and I’m excited to see how it develops! ✨


And now, I’ll show you the **components I’m using for this robot**, and I might make some improvements to it along the way. 🤖✨:

1-the robot body that you can find in the files.

2- 4 servo motors (SG90)

3- 1.30 IIC LCD 

4- ESP32_C3 Super mini 

5- ESP32_C3 Expansion boord  

6- Power Bank Module

7- 3.7V Lithium Polymer Battery 300mAh


From a mechanical engineering perspective ⚙️, the robot has a **roughly square body** ◼️ with four straight legs 🦿. It has **4 DOF**, one for each leg.

I chose **servo motors** 🔧 because they are suitable for the robot’s simple **forward and backward movement** ↔️.

The required **torque** ⚙️ cannot be determined yet because the robot is not finished 🛠️.

A possible limitation is that it cannot **detect obstacles** 🚧 because it has no sensors.

I designed it as a **companion robot** 🤖 with no specific task.
